API-ключі

            
Вставте вміст TXT або виберіть файл. Потрібен хоча б один ключ: NVIDIA чи OpenRouter.

            
            

              
              
              
            

            
Ключі зберігаються локально й не показуються повторно.

            

              Де взяти API-ключі та який формат TXT?
              
NVIDIA API Catalog: оберіть модель → Get API Key.

              
OpenRouter Keys: створіть звичайний API key для completions.

              
NVIDIA_API_KEY=nvapi-ваш_ключ
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ

              
Можна залишити лише один рядок. Не додавайте цей TXT до Git.
