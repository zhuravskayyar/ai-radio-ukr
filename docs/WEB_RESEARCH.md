# Web-пошук для Vector Radio

Vector Radio може передавати AI лише чотири контрольовані інструменти:

- `search_music` — YouTube Data API, потім `yt-dlp`, потім Playwright;
- `search_artist` — метадані MusicBrainz;
- `verify_track` — перевірка пари «виконавець — назва»;
- `open_webpage` — короткий видимий текст публічної HTML-сторінки.

Модель NVIDIA/OpenRouter не керує комп’ютером напряму. Вона формує JSON-команду,
backend перевіряє назву інструмента й аргументи, виконує запит і повертає тільки
обмежені структуровані дані. Під час автоматичного discovery пошукові кандидати
передаються музичному директору як недовірені метадані. Остаточний кандидат все
одно проходить наявну перевірку виконавця, назви, тривалості та джерела перед
додаванням локального файла до бібліотеки.

## Робота за замовчуванням

1. Встановіть залежності:

   ```powershell
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. Web-перевірка музики та браузерний fallback завжди активні. Окремих
   перемикачів у меню немає: Playwright спочатку пробує локальний Microsoft
   Edge, потім Chrome, а потім власний Chromium.
3. Якщо Edge або Chrome відсутній, установіть браузер Playwright окремо:

   ```powershell
   .venv\Scripts\python.exe -m playwright install chromium
   ```

YouTube API key не обов’язковий: без нього `search_music` використовує `yt-dlp`.
Playwright запускається тільки коли попередні способи не повернули результатів.

## Контракт команди

```json
{
  "tool": "search_music",
  "arguments": {
    "query": "modern Ukrainian alternative rock official audio",
    "limit": 20
  }
}
```

Для ручної діагностики цей самий контракт доступний через
`RadioAPI.run_music_research_tool(command)`.

## Межі безпеки

- дозволені тільки чотири відомі команди та їхні оголошені аргументи;
- запити обмежені 240 символами, результати — 20 записами;
- `open_webpage` приймає лише HTTP(S) на стандартних портах;
- localhost, приватні, loopback, link-local та інші непублічні адреси блокуються;
- переходи HTTP повторно перевіряються;
- браузер блокує приватні підресурси, зображення, медіа та шрифти;
- сторінки повних текстів пісень і відомі lyrics-провайдери не відкриваються;
- авторизація, CAPTCHA, платний доступ і захист сайтів не обходяться;
- у звіти й відповіді інструмента не потрапляють API-ключі.

Web-перевірку неможливо випадково вимкнути через UI або API налаштувань:
source-backed підводки є єдиним production-шляхом Vector Radio.
