# Vector Radio Patch 1.0.0.6

Цей патч встановлюється поверх наявної Vector Radio без повторного завантаження Python, TTS і музичної бібліотеки.

## Що додано

- Окремий режим **YouTube Auth** для Chrome, Edge або Firefox.
- Звичайний пошук `yt-dlp` працює без cookies; браузерна сесія використовується лише після підтвердженої помилки age restriction.
- Можна вказати окремий профіль браузера з підтвердженим 18+ акаунтом.
- Якщо авторизована спроба не вдалася, трек пропускається, а фонове поповнення переходить до наступного кандидата без зупинки бібліотеки.
- Після завантаження та перевірки SHA-256 майбутні патчі встановлюються автоматично з перезапуском Vector Radio; кнопка залишається резервом після помилки.
- Версію програми, інсталятора, патча та оновлювача синхронізовано як `1.0.0.6`.

## Встановлення

1. Закрийте Vector Radio, якщо вона відкрита.
2. Запустіть `Vector_Radio_Patch_1.0.0.6.exe`.
3. У «Налаштуваннях» виберіть браузер у полі **YouTube Auth для 18+ fallback** і, за потреби, назву окремого профілю.

Радимо використовувати окремий Google-акаунт: велика кількість автоматичних запитів через cookies може спричинити тимчасові або постійні обмеження акаунта. Налаштування, API-ключі та вже завантажені треки залишаються на місці.
