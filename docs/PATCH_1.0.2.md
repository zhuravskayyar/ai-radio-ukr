# Vector Radio Patch 1.0.2

Це оновлення для вже встановленого Vector Radio. Воно не перевстановлює
приватний Python, PyTorch, StyleTTS2 або голос Адама Вектора й не видаляє
API-ключі, налаштування та локальну музичну бібліотеку.

## Що нового

- автоматичне поповнення AI-бібліотеки ввімкнене одразу після оновлення;
- живий індикатор показує етап пошуку, назву треку, відсоток, обсяг, швидкість
  і приблизний час завантаження;
- вкладка «Бібліотека» показує всі готові локальні треки та їхній розмір;
- програма у фоні перевіряє GitHub Releases, завантажує наступний малий патч,
  перевіряє його SHA-256 і пропонує встановити без повної переустановки;
- до патча додано відсутній модуль LUMEN Downloader, через який онлайн-пошук
  міг не стартувати у встановленій версії.

## Як встановити зараз

1. Закрийте Vector Radio.
2. Запустіть `Vector_Radio_Patch_1.0.2.exe`.
3. Натисніть «Завершити» — бібліотека та налаштування залишаться на місці.

Наступні версії з'являтимуться у вкладці «Бібліотека». Програма сама
завантажить перевірений патч, але встановить його лише після натискання кнопки
«Встановити оновлення», щоб не переривати ефір несподівано.
