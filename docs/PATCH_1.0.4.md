# Vector Radio Patch 1.0.4

Цей патч встановлюється поверх наявної Vector Radio без повторного завантаження Python, TTS і музичної бібліотеки.

## Що виправлено

- Повний стан ланцюжка показано у «Бібліотеці»: AI-планування, пошук, завантаження, перевірка, збереження та готовність до відтворення.
- Для NVIDIA, OpenRouter та інших сумісних провайдерів показується окремий зрозумілий стан.
- API з помилкою ключа або відсутніми кредитами автоматично вимикається до повторного імпорту ключа.
- API з таймаутом, лімітом запитів або тимчасовою помилкою ставиться на паузу; інші провайдери продовжують працювати.
- Технічний JSON сервера більше не показується користувачеві.
- Перезапуск спочатку завершує фоновий пошук, аудіо та WebView2, а потім відкриває новий процес.
- Виправлено Windows mutex, через який після перезапуску могло з’являтися повідомлення, що програма або файл уже відкриті.

## Встановлення

1. Закрийте Vector Radio, якщо вона відкрита.
2. Запустіть `Vector_Radio_Patch_1.0.4.exe`.
3. Після завершення відкрийте Vector Radio звичайним ярликом.

Налаштування, API-ключі та вже завантажені треки залишаються на місці.
