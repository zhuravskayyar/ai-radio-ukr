# Vector Radio 1.0.0.7

Цей реліз оновлює вже встановлену Vector Radio без повторного завантаження Python, голосової моделі та музичної бібліотеки. Налаштування, API-ключі й локальна база даних зберігаються.

## Що нового

- Додано керований пошук музики й фактів у мережі: YouTube Data API, `yt-dlp`, звичайні вебсторінки та Playwright як резерв для JavaScript-сайтів.
- AI може сформувати пошуковий запит, але браузерні дії виконує контрольований backend; модель не отримує необмеженого доступу до комп’ютера.
- Додано перевірку виконавця, назви треку, джерела й фільтрацію плейлистів, каверів, live та remix.
- Покращено паралельну генерацію ефірного тексту й української вимови, словникові винятки та перевірки якості.
- Збережено YouTube Auth fallback для вікових обмежень.
- Playwright включено до runtime-залежностей; програма використовує локальний Edge або Chrome, коли потрібна JavaScript-сторінка.
- Версію програми, інсталятора, патча й автооновлювача синхронізовано як `1.0.0.7`.

## Автоматичне оновлення

Vector Radio перевіряє останній GitHub Release під час запуску. Для версії `1.0.0.6` патч `1.0.0.7` автоматично завантажується, перевіряється за SHA-256, встановлюється та перезапускає програму. Якщо автоматичний запуск не вдався, у вкладці «Бібліотека» лишається кнопка ручного встановлення.

## Ручне встановлення

1. Закрийте Vector Radio.
2. Запустіть `Vector_Radio_Patch_1.0.0.7.exe`.
3. Після завершення відкрийте Vector Radio; бібліотека та налаштування залишаться на місці.

Для чистого встановлення використовуйте `Vector_Radio_Setup_1.0.0.7.exe`.
