# Vector Radio Patch 1.0.3

Це виправлення інтерфейсу для встановленого Vector Radio 1.0.2. Патч не
перевстановлює Python, StyleTTS2 або голос Адама Вектора й не видаляє
API-ключі, налаштування чи завантажені треки.

## Виправлено

- у верхній панелі мінімалістичного інтерфейсу тепер постійно видно кнопку
  «Бібліотека» та кількість готових локальних треків;
- на головному екрані з'явився компактний індикатор пошуку й завантаження;
- натискання на кнопку або індикатор відкриває повний список завантажених
  композицій, їхній розмір і стан автоматичних оновлень;
- вкладка бібліотеки отримала повноцінне темне оформлення Vector Radio;
- виправлено конфлікт стилів, через який старе меню бібліотеки було приховане.

## Встановлення

1. Закрийте Vector Radio.
2. Запустіть `Vector_Radio_Patch_1.0.3.exe`.
3. Після завершення відкрийте програму звичайним ярликом.

Встановлена бібліотека та локальний голос залишаються без змін.
