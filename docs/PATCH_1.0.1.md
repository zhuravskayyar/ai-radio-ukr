# Vector Radio Patch 1.0.1

Це невелике оновлення для вже встановленого Vector Radio 1.0.0. Воно не
перевстановлює Python, StyleTTS2, PyTorch, мовні моделі чи WebView2 і не стирає
налаштування, API-ключі, кеш та музику.

Що виправлено:

- у мінімалістичних налаштуваннях з'явилося видиме підтвердження прав на джерела;
- заблокований пошук більше не запускає порожній фоновий цикл кожні п'ять секунд;
- бібліотека показує людське пояснення, чому пошук ще не почався;
- якщо на робочому столі є попередній локальний проєкт `localRadio`, патч переносить
  його вже завантажені треки у встановлену програму без повторного скачування.

## Як застосувати

1. Закрийте Vector Radio.
2. Запустіть `Vector_Radio_Patch_1.0.1.exe`.
3. Після запуску відкрийте «Налаштування» → «Пошук треків».
4. Підтвердьте право завантажувати й відтворювати вибрані джерела та натисніть
   «Зберегти». Нові треки почнуть додаватися у бібліотеку у фоні.

Використовуйте лише локальні файли та онлайн-джерела, на які маєте право.
