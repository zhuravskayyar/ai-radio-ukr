# Встановлення Vector Radio у Windows

## Що робить інсталятор

`Vector_Radio_Setup_1.0.0.9.exe` встановлює програму для поточного користувача у:

```text
%LOCALAPPDATA%\Programs\Vector Radio
```

Інсталятор не потребує системного Python. Він завантажує офіційний 64-бітний embeddable Python 3.11.9 у приватну папку `runtime`, перевіряє SHA-256 архіву та встановлює компоненти програми. Цей runtime ізольований і не змінює вже встановлені версії Python. Microsoft Edge WebView2 Runtime завантажується лише тоді, коли його немає. Під час оновлення налаштування й локальна SQLite-база не стираються.

Основний голос — не стандартний голос Windows і не Edge TTS. Setup встановлює CPU-версію PyTorch, український StyleTTS2, модулі наголошування та IPA, завантажує зафіксовану модель голосу Адама Вектора й одразу перевіряє її цілісність. Стандартні голоси залишаються тільки аварійним резервом, якщо локальний синтез не може завершитися.

Для першого встановлення потрібні стабільний інтернет, приблизно 3 ГБ вільного місця та кілька хвилин на завантаження голосової моделі. Звичайний запуск після встановлення не перевстановлює компоненти й не потребує інтернету для самого озвучення.

## Валідний API TXT

Файл має бути звичайним текстовим файлом UTF-8, не більшим за 64 КБ. Підтримуються підписані рядки та просто вставлені ключі. Рекомендований формат:

```text
NVIDIA_API_KEY=nvapi-ваш_ключ
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
YOUTUBE_API_KEY=AIza-ваш_ключ
```

Потрібен щонайменше один ключ генеративної моделі:

- NVIDIA починається з `nvapi-`;
- OpenRouter зазвичай починається з `sk-or-v1-`;
- YouTube API необов'язковий і сам по собі не активує AI-ведучого.

У програмі відкрийте шестерню, виберіть TXT або вставте його в поле й натисніть **«Перевірити та зберегти»**. Секрети записуються локально у `data\radio.db`, не повертаються у браузерний інтерфейс і не повинні потрапляти до Git.

## Де взяти ключі

- NVIDIA NIM: відкрийте [NVIDIA API Catalog](https://build.nvidia.com/), виберіть модель, увійдіть у профіль і натисніть **Get API Key**. Офіційна інструкція: [NVIDIA NIM API Quickstart](https://docs.api.nvidia.com/nim/docs/api-quickstart).
- OpenRouter: створіть звичайний inference key на сторінці [OpenRouter Keys](https://openrouter.ai/settings/keys). Management API key для радіо не потрібен.
- YouTube Data API, лише за потреби допоміжних скриптів: створіть проєкт у [Google Cloud Console](https://console.cloud.google.com/), увімкніть **YouTube Data API v3**, потім створіть API key у Credentials.

Не надсилайте реальні ключі у чат, не додавайте `api.txt` або `data\radio.db` до репозиторію. Готовий шаблон є у `api.example.txt`.

## YouTube Auth для віково обмежених треків

У «Налаштуваннях» можна вибрати Chrome, Edge або Firefox і, за потреби, вказати окремий профіль браузера. Vector Radio спочатку завжди запускає звичайний `yt-dlp` без browser cookies. Лише коли YouTube повертає помилку age restriction, той самий кандидат повторюється з cookies вибраного профілю. Якщо авторизація не допомогла, кандидат пропускається й фоновий пошук переходить до наступного треку.

У вибраному профілі потрібно заздалегідь увійти в YouTube під підтвердженим 18+ акаунтом. Радимо використовувати окремий Google-акаунт: велика кількість автоматичних запитів через cookies може призвести до обмежень акаунта. Vector Radio зберігає лише назву браузера та профілю, а не самі cookies чи пароль.

Vector Radio перевіряє GitHub Release під час запуску. Патч завантажується лише разом із коректною SHA-256 сумою, після чого автоматично запускається, закриває програму та відкриває оновлену версію. Якщо автоматичний запуск не вдався, у «Бібліотеці» залишається кнопка ручного встановлення.

## Зміна жанру

У тому самому вікні налаштувань поле **«Жанр і стиль ефіру»** приймає звичайний опис, наприклад:

```text
Український альтернативний рок і метал; енергійний вечірній ефір, без попмузики.
```

Після збереження несумісний старий буфер ротації очищається, а нові добірки формуються вже за новим стилем.

## Повторна збірка

Потрібні Windows 10/11 та Inno Setup 6:

```powershell
winget install --id JRSoftware.InnoSetup -e
.\packaging\build_installer.ps1
```

Результат з'явиться у `dist\Vector_Radio_Setup_1.0.0.9.exe`. Python, PyTorch, мовні моделі й WebView2 не вбудовані в цей файл — інсталятор отримує їх із зафіксованих офіційних джерел під час встановлення. Невеликі вихідні архіви StyleTTS2 вбудовуються в Setup після перевірки SHA-256, тому Git на комп'ютері слухача не потрібен.

Локальна збірка не має комерційного code-signing сертифіката, тому Windows SmartScreen може показати попередження про невідомого видавця. Для публічного релізу Setup потрібно підписати окремим Windows code-signing сертифікатом; це не впливає на локальну перевірку SHA-256.
