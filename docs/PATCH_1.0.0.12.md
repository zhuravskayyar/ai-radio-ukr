# Vector Radio 1.0.0.12

Автоматична web-перевірка музики та браузерний fallback.

## Змінено

- Додано тему Boombox з касетною декою, сегментним дисплеєм, еквалайзером і
  повними елементами керування; вибір теми зберігається.
- Обкладинки YouTube безпечно кешуються локально й відображаються на касеті.
- Посилено зіставлення назв і Google/YouTube-пошук, щоб завантажувач не підміняв треки.
- Покращено радіочергу, завершення відтворення та семиденний cooldown треків.
- Web-перевірка музики й браузерний fallback завжди активні.
- Застарілі перемикачі цих функцій прибрано з простого та розширеного меню.
- Під час оновлення старі значення `0` автоматично змінюються на `1`.
- UI та API налаштувань більше не можуть випадково вимкнути source-backed підводки.
- Додано перевірку повторених і майже однакових речень усередині однієї підводки.
- Для музичних історій зафіксовано порядок: спочатку перевірена історія, потім
  рівно одне оголошення треку в останньому реченні.
- Невдалий текст автоматично повертається тому самому AI-провайдеру на одну
  редакторську спробу; в ефір потрапляє лише повторно перевірений варіант.

API-ключі, музична бібліотека та завантажені файли зберігаються.
