# Vector Radio 1.0.0.8

Терміновий hotfix запуску після оновлення `1.0.0.7`.

## Виправлено

- До Patch і повного Setup додано `radio_pronunciation.py`, який потрібен новому рушію української вимови.
- До Patch додано актуальний `data/tts_pronunciations.json` із виправленими словниковими вимовами.
- Усунуто падіння під час запуску з помилкою `ModuleNotFoundError: No module named 'radio_pronunciation'`.
- Додано автоматичний тест, який не дозволить знову випустити Patch або Setup без модуля вимови.
- Версію програми, launcher, updater, Patch і Setup синхронізовано як `1.0.0.8`.

## Оновлення

- Якщо `1.0.0.7` не запускається, завантажте й один раз запустіть `Vector_Radio_Patch_1.0.0.8.exe` вручну.
- Версії `1.0.0.6` та старіші отримають справний `1.0.0.8` через вбудований updater.
- Налаштування, API-ключі, музична бібліотека й завантажені файли зберігаються.

Для чистого встановлення використовуйте `Vector_Radio_Setup_1.0.0.8.exe`.
