# Vector Radio 1.0.0.9

Hotfix швидкого запуску рушія української вимови.

## Виправлено

- Усунуто тривале зависання перед появою вікна після встановлення нового pronunciation engine.
- Якщо бібліотека `pronouncing` не знаходить слово, програма більше не перебудовує повний CMUdict для кожного промаху.
- Прямий `cmudict` збережено як резерв лише для середовищ без `pronouncing`.
- Збережено виправлення `1.0.0.8`: Patch і Setup містять `radio_pronunciation.py` та актуальний словник вимови.
- Додано regression-тест для швидкого шляху CMUdict miss.

Налаштування, API-ключі, музична бібліотека й завантажені файли не змінюються.
